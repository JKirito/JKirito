### 🏗️ What I build

- **AI agent platforms.** Agent runtimes that run durably, stream results in real time, and connect to tools, memory, and MCP. I build them for the web and for the apps people already work in.
- **Full-stack products.** Internal platforms covering analytics, search, content management, and admin, built across both the frontend and the backend.
- **The infrastructure under them.** Auth, queues, observability, CI/CD, and cloud deployments, all built and run by me.

I usually take a product from an idea to production on my own, then keep improving it.
